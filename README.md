## 🚀 Key Showcase Pillars

### 1. Community Circles
Specialized developer and research circles collaborating in weekly coding labs:
* **Artificial Intelligence**: Agentic workflows, LLM orchestration, and vector search.
* **Cybersecurity & Defense**: Network protocols, vulnerability scanning, and hardening.
* **Distributed Systems**: High-concurrency architectures and telemetry.

### 2. Education Pathways
Immersive programs designed for schools, universities, and professional cohorts:
* **Geniusphere School Series**: 1-day coding logic and web-building workshops.
* **University Guilds**: Sponsoring student coding clubs and academic bootcamps.
* **Cohort Training**: Rigorous, multi-week programs coached by domain specialists.

### 3. Events & CTFs
* **Summits**: Live technical presentations, project showcases, and keynote panels.
* **Practical Wargames**: Capture-the-flag tournaments and AI hackathons replacing traditional lectures.

## 🛠️ Architecture & Tech Stack
This application is engineered as a modern Single-Page Application (SPA):
* **Frontend**: React 18, TypeScript, TailwindCSS, and Framer Motion (page transitions).
* **Router**: React Router v6.
* **Icons**: Lucide React.
* **Build Tool**: Vite.

```text
src/
├── components/          # Reusable UI cards, modally dynamic forms, and layouts
│   ├── cards/           # TrainingCard, MediaCard, StoryCard
│   ├── layout/          # Fixed Navbar, Footer, Mobile Navigation drawers
│   └── ui/              # PageHero, SectionHeading, Breadcrumb, Modals
├── data/                # Mock data layer feeding the repositories
├── contexts/            # Modal and telemetry application state contexts
├── models/              # TypeScript interface types and data schemas
├── pages/               # Page components (Home, Education, Training, Careers, etc.)
└── styles/              # Global Tailwind style configuration and animation keyframes
```

## 💻 Local Setup & Development

### 1. Clone the repository
```bash
git clone https://github.com/PavanKumar-HQ/Brandex-Community.git
cd Brandex-Community
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
