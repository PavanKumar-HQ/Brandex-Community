# Brandex Community Platform

Welcome to the **Brandex Community Platform** repository. This is the official digital showcase and education platform for Brandex's emerging technology communities, school workshops, research initiatives, and live events.

## Features

- **Education Pathways**: Discover school & youth programs, college initiatives, professional skills, and hands-on workshops.
- **Community Circles**: Join specialized technology circles in Artificial Intelligence, Cybersecurity, and Swiss UX.
- **Training Catalog**: Browse rigorous, cohort-based courses designed to elevate your technical expertise.
- **Events & Summits**: View upcoming technical summits, capture-the-flag wargames, and coding labs.
- **Stories & Impact**: See the difference we're making across student and professional demographics.

## Technology Stack

- **React**: Frontend UI framework
- **Vite**: Fast development build tool
- **Tailwind CSS**: Utility-first CSS framework for rapid styling
- **React Router v6**: Client-side routing
- **Framer Motion**: Smooth entry and micro-animations

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
